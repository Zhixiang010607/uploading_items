# TEMU 商品发布助手

公网网页：<https://yanyujie-upload-item-d1ab8962386-1465086870.tcloudbaseapp.com/>

## 当前流程

- 从 XLSX、XLS 或 CSV 第一张工作表读取产品标题。
- 选择完整图片文件夹，严格要求 `1.1` 至 `1.6`、`2.1` 至 `2.6`，一直连续到 `N.6`。
- 禁止缺号、多余文件、重复编号、前导零、子文件夹和不支持的图片格式。
- 每个产品使用六张轮播图，`N.1` 同时作为预览图。
- 选择妙手 ERP 已绑定店铺。个人产品模板和 SKU 模板属于妙手网页内部数据，不能用开放平台 App ID / Key 直接读取。
- `chrome-extension` 提供只读 Chrome 辅助插件，在已登录的妙手页面中分页读取个人产品模板和 SKU 模板，并通过浏览器本地存储同步到发布助手。插件不读取 Cookie，也不包含新增、修改、删除或发布接口。
- 浏览器计算每张图片的 SHA-256，以 6 路并发直传腾讯云；单次上传超过 60 秒会判为失败并进入重试，单张即时重试最多 5 次。
- 云函数按批次逐张核对对象路径、文件大小和 SHA-256。整批完全一致后，才允许导入妙手图片空间。
- 单张失败不会中断整批；常规轮次结束后还会执行一次最终恢复，只补传云端核验失败的图片。
- 相同清单可断点续传，只上传或导入尚未成功的项目。上传时可切换到其他软件，但必须保持浏览器页面开启。
- 当前流程不保存草稿。
- 当前线上配置为安全测试模式，真实上传、导入和商品发布均被前端写入锁阻止。

## 云端组成

- 静态网站：CloudBase 静态网站托管。
- API：CloudBase 云函数 `temu-api`，HTTP 网关路径 `/api`。
- 图片：CloudBase 云存储桶 `temu-product-images`。
- 清单：CloudBase PostgreSQL 表 `temu_upload_batches` 和 `temu_upload_items`。

妙手 AppSecret 只保存在云函数环境变量中，不写入网页或 Git。妙手应用已审核通过；网站固定使用 TEMU 全托管 `pddkj` 接口。当前全托管采集箱列表可读取，店铺列表接口仍缺少权限，网页会从采集箱绑定关系提取店铺 ID。个人产品模板和 SKU 模板由 `chrome-extension` 使用当前妙手网页登录会话只读同步。

临时图片清理接口只接受状态为 `published` 的整批任务，不能在发布完成前误删图片。

## 压力测试

`scripts/stress-upload.js` 只测试清单、云存储和云端核验，不调用妙手导入或商品发布接口。2026-10-04 使用 6 路并发完成 1,998 张、每张 512,000 字节、共 1,022,976,000 字节（约 976.6 MiB）的测试，活跃运行时间约 52 分钟，最终结果为 `1998/1998`、失败数 `0`。测试中发现一条请求可能长期无响应，因此补充了 60 秒单次超时和断点续传；恢复时保留已核验的 1,985 张，只补传剩余 13 张。清单创建耗时由约 100 秒降至 9.6 秒。4、6、8 路的小批量对比显示 6 路更适合当前环境，8 路会因限流变慢。测试对象和测试清单随后全部清理。
