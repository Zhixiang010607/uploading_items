# 妙手模板与草稿助手

此 Chrome 扩展读取当前已登录妙手 ERP 账号中的 TEMU 全托管店铺、产品模板和 SKU 模板，并把精简后的 ID、名称保存到浏览器本地。发布助手完成图片校验和导入后，可明确请求扩展把同一个产品模板和 SKU 模板反复应用到每个产品，并创建未发布草稿。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `chrome-extension`。

## 使用

1. 登录妙手 ERP，打开产品模板页面。
2. 点击 Chrome 工具栏中的“妙手模板与草稿助手”。
3. 点击“从当前妙手页面同步”。
4. 可点击“真实只读预检模板”，确认妙手能把当前产品模板和 SKU 模板组合成完整商品；该检查不会创建商品。
5. 打开或刷新 TEMU 商品发布助手，产品模板和 SKU 模板会出现在下拉框中。

## 权限边界

- 日常同步只调用 `getAllShopV2`、`searchTemplateList` 和 `searchSkuPropTemplate` 三个 GET 列表接口；店铺接口不可用时会退回只读的 `getAllShop` GET 接口。
- 只读预检会临时读取所选产品模板，并调用妙手现有的 SKU 模板重建逻辑；模板完整内容不会保存到扩展存储。
- 不读取或保存妙手 Cookie、App Secret。
- 草稿任务只接受发布助手发出的“创建未发布”请求，不调用直接发布接口。
- 直接发布能力未接入，扩展中没有直接发布接口。
